# Dashboard Plugin v2

Dashboard Plugin v2 is a standalone WordPress shortcode plugin. It reads one value from a publicly published Google Sheet and renders it with configurable text and number formatting.

It has no Elementor dependency. Elementor can still be used as the page builder: place a normal Elementor **Shortcode** widget on the page and paste the shortcode into it.

## Branch and version

- Branch: `v2`
- Plugin version: `2.0.0`
- Shortcode: `[dashboard_metric]`

## Installation

1. Download the ZIP from the `v2` branch.
2. In WordPress, go to **Plugins → Add New → Upload Plugin**.
3. Upload the ZIP, install it, and activate **Dashboard Plugin**.
4. Open **Settings → Dashboard Plugin**.
5. Paste the published Google Sheet URL, optionally set a default tab name, and save.

The ZIP generated by GitHub should contain the plugin folder and `dashboard-plugin.php` at its top level after extraction.

## Google Sheet setup

The source must be published to the web as CSV. The sheet can be a small public output sheet populated from a private working sheet; do not publish confidential data.

In Google Sheets:

1. Open the output spreadsheet.
2. Choose **File → Share → Publish to web**.
3. Select the required tab, choose **Comma-separated values (.csv)**, and publish.
4. Paste the spreadsheet URL—not a private API credential—into the plugin settings.

## Basic shortcode

```text
[dashboard_metric]
```

With the requested display:

```text
[dashboard_metric cell="B2" before="So far we have saved" suffix=" KG" after="Of food from landfill"]
```

This produces three lines:

```text
So far we have saved
194 KG
Of food from landfill
```

## Shortcode attributes

| Attribute | Default | Purpose |
| --- | --- | --- |
| `source_url` | settings value | Override the published Google Sheet URL for this instance. |
| `sheet` | settings value | Select the published tab name. |
| `cell` | `B2` | Cell to display, such as `B2` or `C5`. |
| `before` | `So far we have saved` | Text above the value. |
| `after` | `Of food from landfill` | Text below the value. |
| `prefix` | empty | Text immediately before the value. |
| `suffix` | ` KG` | Text immediately after the value. |
| `decimals` | `-1` | Keep the source formatting with `-1`, or use `0`, `1`, `2`, etc. |
| `thousands` | `,` | Thousands separator when formatting a number. |
| `decimal` | `.` | Decimal separator when formatting a number. |
| `fallback` | `Data currently unavailable` | Message shown when the sheet cannot be read. |
| `class` | empty | Add one or more custom CSS classes. |

Example with a custom source and formatting:

```text
[dashboard_metric source_url="https://docs.google.com/spreadsheets/d/SPREADSHEET_ID/edit" sheet="WebsiteData" cell="B2" decimals="0" before="So far we have saved" suffix=" KG" after="Of food from landfill" class="impact-metric"]
```

## Styling

The plugin outputs these classes:

- `.hayfam-dashboard-metric`
- `.hayfam-dashboard-metric__before`
- `.hayfam-dashboard-metric__value`
- `.hayfam-dashboard-metric__after`

Use the `class` attribute to target a specific instance from your theme or Elementor custom CSS.

```css
.impact-metric {
  text-align: center;
}

.impact-metric .hayfam-dashboard-metric__value {
  color: #2f855a;
  font-size: 4rem;
  font-weight: 700;
  line-height: 1;
}
```

The value is cached for five minutes by default. The cache duration can be changed in the plugin settings.

## Plugin structure

- `dashboard-plugin.php` — bootstrap and shortcode registration.
- `includes/class-dashboard-plugin-shortcode.php` — shortcode rendering and formatting.
- `includes/class-dashboard-plugin-sheets-client.php` — public Google Sheets CSV requests.
- `includes/class-dashboard-plugin-cache.php` — transient-style WordPress option cache.
- `includes/class-dashboard-plugin-settings.php` — admin settings screen.
- `assets/css/dashboard-plugin.css` — baseline output styling.

## Security and compatibility

- Only publish non-sensitive output data.
- The plugin does not request Google credentials.
- The plugin does not load Elementor classes or Elementor widget files.
- Requires WordPress 6.4+ and PHP 7.4+.
